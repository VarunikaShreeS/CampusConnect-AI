CampusConnect AI

The Ultimate Gamified Portal for Campus Ambassadors.

CampusConnect AI is a premium Streamlit-based dashboard designed to automate and gamify community management. It empowers ambassadors with AI-driven content tools, real-time leaderboard tracking, and verified digital identification.

Key Features
Task Marketplace: 
A gamified mission control where ambassadors can submit evidence for tasks and earn XP (Experience Points).

GitHub Auditor: 
Integrated profile analysis to help recruiters and leads see the technical impact of members.

AI Co-Pilot:
Built-in social media caption generator to maintain brand voice across LinkedIn and X.

 Global Leaderboard: 
 Real-time ranking system to spark healthy competition among campus leads.

 Digital ID & QR: 
 Instant generation of verified digital identity cards and referral QR codes for offline networking.

Premium UI: 
A modern, dark-themed interface built using custom CSS and Inter Google Fonts.

Tech Stack
Frontend/Backend: Streamlit

Data Handling: Pandas

Visualization: Plotly Express

Utilities: qrcode for ID generation, requests for API interaction.

Styling: Custom CSS Injection.
